# Weather Agent MCP - Сервис прогноза погоды с использованием AI

## Описание проекта

Weather Agent MCP — это Go-приложение, которое предоставляет REST API для получения прогнозов погоды с использованием искусственного интеллекта. Сервис интегрируется с GigaChat LLM (от Сбербанка) и MCP (Model Context Protocol) Weather Server для получения актуальных метеоданных.

**Основные возможности:**
- Обработка естественно-языковых запросов о погоде
- Интеграция с MCP Weather Server для получения реальных данных
- Модульная архитектура с использованием цепочек обработки (chains)
- REST API для интеграции с другими системами
- Поддержка русского языка в запросах и ответах

## Быстрый старт

### Предварительные требования

1. **Go 1.25.7** или выше
2. **Node.js 18+** (для MCP Weather Server)
3. **Аккаунт GigaChat** с API ключом
4. **npm** или **npx** для запуска MCP сервера

### Установка и запуск

1. **Клонирование и установка зависимостей:**
```bash
git clone <репозиторий>
cd weather-agent-mcp
go mod download
```

2. **Настройка конфигурации:**
Создайте файл `config.env` (или отредактируйте существующий):
```env
AUTH_KEY=ваш_ключ_gigachat
IP=127.0.0.1
PORT=8080
TIMEOUT=2
```

3. **Запуск MCP Weather Server:**
```bash
npx -y @dangahagan/weather-mcp@latest
```
*Примечание: MCP сервер запускается автоматически при старте приложения.*

4. **Сборка и запуск приложения:**
```bash
go build -o weather-agent
./weather-agent
```

## Конфигурация

### Настройка MCP сервера

MCP Weather Server автоматически запускается как subprocess. Для ручной настройки можно изменить параметры в `weather/mcp.go`:

```go
cmd := exec.Command("npx", "-y", "@dangahagan/weather-mcp@latest")
```

## 📊 Логирование

Приложение использует структурированное логирование с несколькими уровнями:

- **DEBUG**: Детальная отладочная информация
- **INFO**: Основные события приложения
- **WARN**: Предупреждения
- **ERROR**: Критические ошибки

Логи выводятся в консоль и сохраняются в файл `server.log`.

## 🔄 Процесс обработки запроса

1. **Получение запроса**: REST API принимает POST запрос с промптом
2. **Извлечение параметров**: LLM анализирует запрос и извлекает город и период
3. **Парсинг параметров**: JSON парсится в структурированные данные
4. **Запрос к MCP**: Отправка запроса к MCP Weather Server
5. **Форматирование ответа**: LLM формирует читаемый ответ с рекомендациями
6. **Возврат результата**: Ответ возвращается клиенту

## Устранение неполадок

### Проблема: "Не удалось инициализировать MCP weather сессию"
**Решение:**
1. Убедитесь, что установлен Node.js 18+
2. Проверьте доступность npm/npx
3. Запустите MCP сервер вручную: `npx -y @dangahagan/weather-mcp@latest`

### Проблема: "Не удалось подключиться к LLM модели"
**Решение:**
1. Проверьте корректность AUTH_KEY в config.env
2. Убедитесь, что аккаунт GigaChat активен
3. Проверьте сетевое подключение

### Проблема: "Сервер не запускается на указанном порту"
**Решение:**
1. Проверьте, не занят ли порт другим приложением
2. Убедитесь, что у вас есть права на использование порта
3. Попробуйте изменить порт в config.env
